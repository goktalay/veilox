# Credits

## Libraries

- None. All motion is plain JavaScript on a canvas.

## Font

- **Geist**, in `fonts/geist.woff2`. Replace it or use a font you own or license before you publish.

## Particle data

- `assets/points.bin`: dot positions for the hands, sampled from artwork made while designing this template (part of it was generated with AI). No photographs or image files ship with the template.
- `assets/brain.bin`: dot positions sampled from the fsaverage5 average brain surface published with FreeSurfer (as bundled with the nilearn Python library).
